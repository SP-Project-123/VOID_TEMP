### 5. All Math Explained
- Coordinate system: pixel vs grid (position / TILE_PX)
- `TILE_PX = TILE_SIZE * RENDER_ZOOM = 8 * 4 = 32`
- Grid-to-pixel: `x * TILE_PX`, pixel-to-grid: `(int)(pos / TILE_PX)`
- Manhattan distance: `abs(r1-r2) + abs(c1-c2)` (spawn distance checks)
- Euclidean distance: `sqrtf(dx*dx + dy*dy)` (collision, movement normalization)
- Direction normalization: `(dx/len, dy/len)` for unit vector
- AABB collision: `CheckCollisionRecs()` for melee/projectile hits
- Circle-rect collision: `CheckCollisionCircleRec()` for melee attacks
- Bounding box corners: 4-point collision for player/enemy movement
- Attack rectangle math: directional offset + size expansion
- Health percentage: `health / maxHealth` for bar rendering
- Camera: 2.5x zoom centered on player
- Animation frame: `(int)(GetTime() * 8.0f) % 2`
- Difficulty multipliers: speed × (0.8 / 1.0 / 1.25), HP × (0.75 / 1.0 / 1.35)
- Level multipliers: speed × (1 + level × 0.2), HP × (1 + level × 0.2)

### 7. Enemy Behavior — Every Type
- Snake: chase player, uses tilemap sprites on level 0, sprites tileset on level 1
- Spider: chase + ranged projectiles every 1.8s
- Ghost: velocity-based movement, bounces off walls

- Algorithm: boss, chase + spawns Brainrot God on death
- Brainrot God: 3-phase attack cycle (Skibidi Blast → Ohio Storm → Sigma Shockwave), only damaged by memory fragments (200 dmg each)

### 9. "Changing X Affects Y" Dependency Map
- Changing `TILE_PX` → affects window size, movement speed, collision, rendering
- Changing `currentLevel` → affects tile classification, enemy stats, spawn logic, tilemap loading
- Changing `difficulty` → affects enemy HP and speed multipliers
- Changing `MAX_ZOMBIES` → affects array sizes, spawn slot availability
- Changing tile walkability lists → affects pathfinding, spawning, collision
- Changing `GameState_Init()` → affects starting state for all systems
- Changing `GetEnemyProperties()` → affects all combat balance
- Adding a new enemy type → needs: EnemyType enum, properties in GetEnemyProperties, AI in UpdateZombies, drawing in DrawGame, spawn logic in SpawnZombie
- Adding a new tile type → needs: constant in common.h, classification in GetTileType, handling in walkability checks
- Adding a new game state → needs: enum value, case in UpdateGame switch, case in DrawGame switch
